# 🐾 Муркин мир — большая версия

**Муркин мир** — браузерная игра про кошку, её дом, сад и мини-игры. Проект рассчитан на публикацию как статический сайт через GitHub Pages.

## Что уже входит

### 3D-мир
- Процедурная 3D-модель кошки с ушами, глазами, мордочкой, усами, лапами, хвостом, ошейником и аксессуарами.
- Анимации: ходьба, бег, прыжок, сон, умывание, игра и реакция на ласку.
- 3D-комната с окном, мебелью, ковром, освещением и тенями.
- 3D-сад с деревом, цветами, дорожкой, прудом, оградой и грядками.
- Вращение камеры мышью или пальцем.

### Дом и питомец
- Покупка мебели и украшений.
- Разные окрасы и аксессуары для кошки.
- Уход за Муркой: кормление, ласка, игра, сон, купание и прогулка.
- Показатели сытости, радости, энергии и чистоты.

### Сад
- Шесть грядок.
- Посадка семян, полив в три этапа и сбор урожая.
- Монеты, опыт и дополнительные семена за урожай.

### Мини-игры
- **Садовые самоцветы** — Match-3.
- **Найди пары** — карточная игра на память.
- **Лампочки** — логическая головоломка Lights Out.
- **Запомни цвета** — последовательность в стиле Simon.
- **Пятнашки** — числовая головоломка.
- **Кошачьи гонки** — аркадная гонка с монетами и препятствиями.
- **Рыбалка** — игра на точность и реакцию.
- **Поиск сокровищ** — поиск предметов под карточками.

### Прогресс
- Общие монеты и очки опыта.
- Уровни и бонус за повышение уровня.
- Задания с наградами.
- Автоматическое сохранение прогресса в браузере.

## Как запустить на компьютере

Three.js подключается с CDN, поэтому нужен интернет.

1. Распакуйте архив.
2. Откройте папку `murkin_world_full` в Visual Studio Code.
3. Установите расширение **Live Server**, если оно ещё не установлено.
4. Нажмите правой кнопкой по `index.html` → **Open with Live Server**.
5. Игра откроется в браузере.

Не запускайте `game.js` двойным щелчком. ES-модули и загрузку 3D-библиотеки нужно проверять через локальный веб-сервер.

## Как опубликовать на GitHub Pages

1. Создайте на GitHub новый **Public repository**, например `murkin-world`.
2. Распакуйте архив на компьютере.
3. Откройте папку `murkin_world_full`.
4. Загрузите **всё содержимое папки** в корень репозитория. Сам ZIP загружать не нужно.
5. Проверьте, что `index.html` лежит в корне репозитория, а папка `assets` находится рядом с ним.
6. В репозитории откройте **Settings → Pages**.
7. В **Build and deployment** выберите **Deploy from a branch**.
8. В качестве Branch выберите `main`, папку `/ (root)`, затем нажмите **Save**.
9. Дождитесь публикации. Адрес игры появится в разделе Pages.

После следующего обновления проекта заменяйте в репозитории одноимённые файлы новыми. Папку `assets` также нужно оставить.

## Важно

- Игра сделана на HTML, CSS, JavaScript и Three.js. Сборщик, Node.js и серверная база данных для GitHub Pages не нужны.
- Для загрузки Three.js и шрифта нужен интернет.
- Сохранение хранится в `localStorage` браузера конкретного игрока. У разных игроков будут разные сохранения.
- Если ранее в браузере была игра «Пазл-Домик», первая загрузка может перенести её монеты и часть покупок.
- Очистка данных сайта в браузере удалит сохранение. Для сброса прогресса можно удалить данные сайта `murkin-world`.
- Текущая версия — большая играбельная основа. В ней процедурная стилизованная 3D-графика, а не фотореалистичные модели или готовая игра уровня крупной студии.
- Перед коммерческим распространением добавьте собственную лицензию и контактные данные. Сейчас отдельная лицензия намеренно не установлена.

## Советы по проверке перед публикацией

Проверьте игру через Live Server: откройте домик, переключитесь в сад, покормите Мурку, купите декор, посадите семена и запустите каждую мини-игру. В консоли браузера (F12 → Console) не должно быть ошибок загрузки.
