# 🐾 Кошкин дом

Браузерная 3D-игра про кошку. В этой версии Мурка умеет гулять, бегать, прыгать, спать, умываться и играть. Также есть комната, магазин мебели, монеты и мини-игра на поиск пар.

## Как запустить локально
Откройте папку в Visual Studio Code и запустите `index.html` через расширение Live Server. Для загрузки Three.js требуется интернет.

## Публикация на GitHub Pages
1. Создайте Public-репозиторий на GitHub.
2. Загрузите содержимое этой папки прямо в корень репозитория (не сам ZIP).
3. В Settings → Pages выберите Deploy from a branch, ветку `main` и папку `/ (root)`, затем Save.
4. Дождитесь публикации сайта.

## Файлы
- `index.html` — разметка страницы и кнопки действий кошки.
- `style.css` — оформление, включая новые кнопки.
- `game.js` — 3D-сцена, кошка, анимации, магазин и мини-игра.
- `.nojekyll` — служебный файл для GitHub Pages.

Игра хранит прогресс в localStorage браузера игрока. Three.js загружается с jsDelivr CDN.
